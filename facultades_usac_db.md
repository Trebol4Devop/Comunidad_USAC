# Facultades USAC — Dataset para Base de Datos

> **Fuente:** [Portal de Registro y Estadística USAC](https://portalregistro.usac.edu.gt/facultades) — Guía de Inscripción 2026
>
> **Campos relevantes:** Facultad (ID + nombre) · Código de carrera (ID único) · Nombre de la carrera · Sede/Ubicación · Modalidad del plan (Diario / Sabatino / Dominical) · Sitio oficial de la facultad.
>
> **Uso:** filtrar el marketplace, organizar grupos de estudio y categorizar el foro estudiantil.

---

## Estructura de los códigos

El código `facultad-unidad-carrera` es el identificador único:
- Primer número = facultad (`01` Agronomía … `10` Veterinaria; `77` Humanidades).
- Segundo número = unidad/sede (ej. `00` Campus Central; en Humanidades cada número es una extensión).
- Tercer número = carrera.

Ejemplo: `01-00-02` → Facultad de Agronomía, Campus Central, Ingeniería Agronómica en Sistemas de Producción Agrícola.

## Modelo de datos sugerido

```
facultad:  { id: "01", nombre: "Facultad de Agronomía", sitio_oficial: "http://fausac.gt/" }
carrera:   { codigo: "01-00-02", facultad_id: "01", nombre: "Ingeniería Agronómica en Sistemas de Producción Agrícola",
             sede: "Campus Central", modalidad: ["Diario","Sabatino","Dominical"] }
```

**Notas de fiabilidad:**
- Los datos provienen de la Guía de Inscripción 2026; algunas celdas vienen vacías en la fuente (sede, modalidad) y se marcaron con el valor más probable.
- La Facultad de Humanidades publica una fila por cada sede y modalidad, por eso algunos códigos se repiten con distinta modalidad (ej. `77-00-23` Diario y `77-01-23` Sabatino).
- La Facultad de Ciencias Jurídicas (04) no publica su oferta en el portal.
